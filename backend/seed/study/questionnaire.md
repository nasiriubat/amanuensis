# End-of-study questionnaire

Answer for the paper you wrote with Paper Writer. Ten minutes. There are no right answers.

## Part A: System Usability Scale

For each statement, mark 1 (strongly disagree) to 5 (strongly agree).

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## Part B: Trust, control and friction

11. **Trust.** How often did a drafted section state something that was not in your material?
    Never / Once or twice / Several times / Often. If it happened, give one example.
12. **Control.** Did you feel the paper was yours? 1 (the tool's paper) to 5 (my paper). What
    made the difference?
13. **Placeholders.** `[NEEDS]` and `[CITE]` placeholders: helpful, neutral, or annoying?
    Roughly how many were left when you exported?
14. **Where you got stuck.** Name the step where you lost the most time or nearly gave up, and
    what you did about it.
15. **Decisions.** Were there moments where the tool asked you to decide something you did not
    understand or care about? Which ones?

## Part C: Outcome

16. What state is your paper in now? Notes only / Partial draft / Complete draft / Ready to
    submit after edits.
17. Would you use it for your next paper? Yes / Yes, for some steps / No. Which steps?
18. Anything else the developers should hear.
